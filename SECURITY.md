# Security Policy

## Reporting a vulnerability

Please do not open a public GitHub issue for a suspected security vulnerability.

Report security concerns privately to **vision79slu@gmail.com** with:
- the affected page, endpoint, or component;
- steps to reproduce the issue;
- the potential impact;
- any proof-of-concept details needed to confirm the problem.

Do not include customer data, credentials, access tokens, encryption keys, or other secrets in the report.

V79 Digital will review credible reports and prioritise remediation according to severity and exploitability.

## Supported version

The currently deployed production release on the `main` branch is the supported version. Older deployments should be upgraded rather than patched independently.

## Scope

Good-faith testing should avoid destructive actions, denial-of-service activity, social engineering, privacy violations, or accessing data that does not belong to the tester.
